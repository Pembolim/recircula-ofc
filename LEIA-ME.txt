RECIRCULA - CONFIGURACAO DE PRODUCAO
=====================================

STACK
- PHP 8.2 + Apache (Docker)
- PostgreSQL no Supabase
- Hospedagem PHP no Render
- Fotos guardadas no campo bytea do PostgreSQL, para nao depender do disco temporario do servidor.

FUNCIONALIDADES
- Cadastro, login e logout.
- Publicacao de objetos para doacao ou troca.
- Upload de fotos JPG, PNG e WEBP (ate 3 MB).
- Catalogo com busca pelo titulo.
- Solicitacoes, aceite/recusa e chat por solicitacao.
- Conclusao de negociacoes.
- Consulta e exclusao dos proprios anuncios.

SUPABASE
1. O projeto Supabase precisa ter o esquema PostgreSQL de database.sql.
2. No Dashboard do Supabase, abra Connect e escolha Session pooler.
3. Copie o host indicado pelo Supabase. Nao tente montar o hostname manualmente.
4. Em Database Settings, defina/reset a senha do banco se ainda nao houver uma senha conhecida.
5. No Render, configure as variaveis descritas abaixo. Nunca coloque a senha no GitHub.

RENDER - VARIAVEIS DE AMBIENTE
SUPABASE_DB_HOST=<host copiado de Connect / Session pooler>
SUPABASE_DB_PORT=5432
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres.<PROJECT_REF>
SUPABASE_DB_PASSWORD=<senha do banco, cadastrada diretamente no Render>

A senha deve ser guardada como variavel secreta no Render. Nao a envie pelo GitHub nem a coloque em config.php.

DEPLOY
- O servico Render usa o Dockerfile da raiz do repositorio.
- O Render faz deploy automatico a partir da branch main.
- URL atual do servico: https://recircula-ofc.onrender.com

IMAGENS
- As imagens sao armazenadas como bytea na tabela public.objetos.
- imagem.php entrega a imagem para as paginas do site.
- O diretório uploads antigo nao e mais usado pelo fluxo de upload.

BANCO DE DADOS
- database.sql contem o esquema PostgreSQL.
- No Supabase, as tabelas sao: usuarios, objetos, solicitacoes e mensagens.
- O esquema foi criado em um projeto Supabase na regiao sa-east-1.

IMPORTANTE
Este e um projeto didatico. Antes de abrir ao publico, revise seguranca, privacidade,
limites de upload, politicas de abuso, backup e controles de acesso.
